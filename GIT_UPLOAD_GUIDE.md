# 🐙 GUÍA PASO A PASO PARA SUBIR TU PROYECTO A GITHUB

El proyecto **POSGRADO CRM ESAM** ya tiene todos sus archivos limpios, estructurados y configurados con su archivo `.gitignore` profesional para subir a GitHub.

---

## 🌟 Método 1: Subida Directa desde la Web de GitHub (MÁS FÁCIL - Sin instalar programas)

1. Ingresa a **[GitHub.com](https://github.com)** e inicia sesión con tu cuenta.
2. Haz clic en el botón verde **New** (o el signo **+** arriba a la derecha > **New repository**).
3. Configura tu repositorio:
   - **Repository name**: `posgrado-crm-esam`
   - **Visibility**: Elige **Private** (Privado) o **Public** (Público).
   - Deja sin marcar la casilla "Add a README file".
   - Haz clic en **Create repository**.
4. En la pantalla que aparece, haz clic en el enlace azul que dice: **`uploading an existing file`**.
5. Arrastra y suelta los archivos principales del proyecto (`server.py`, `package.json`, `Dockerfile`, `Procfile`, `render.yaml`, carpeta `src`, etc.).
6. Haz clic en el botón verde **Commit changes**.

¡Listo! Tu código fuente estará publicado en tu cuenta de GitHub.

---

## 💻 Método 2: Usando GitHub Desktop (Aplicación Oficial Gratuita)

1. Descarga e instala **[GitHub Desktop](https://desktop.github.com)**.
2. Abre GitHub Desktop e inicia sesión con tu cuenta de GitHub.
3. Ve al menú superior **File** > **Add local repository...**
4. Haz clic en **Choose...** y selecciona la carpeta de tu proyecto.
5. Haz clic en **Add Repository**.
6. En la parte superior presiona **Publish repository**, asígnale el nombre `posgrado-crm-esam` y haz clic en **Publish**.

---

## 🚀 Conexión Final con la Nube Gratuita (Render / Vercel)

Una vez subido a GitHub:
- Entra a **[dashboard.render.com](https://dashboard.render.com)** o **[vercel.com](https://vercel.com)**.
- Inicia sesión con GitHub, selecciona tu repositorio `posgrado-crm-esam` y presiona **Deploy**.
- ¡Tu CRM estará online las 24 horas del día de forma 100% gratuita!
